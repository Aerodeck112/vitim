=== VITIM Connector ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.2.0
License: GPLv2 or later

Conectează site-ul la panoul VITIM.

== Description ==
* Trimite la fiecare oră starea site-ului: versiunea WordPress și PHP, tema, pluginurile cu actualizări în așteptare.
* Actualizările de pluginuri, teme și WordPress apar automat în jurnalul de lucrări VITIM, vizibil clientului.
* Comunicarea e semnată (HMAC-SHA256); pluginul nu primește comenzi de la distanță.

== Installation ==
1. Module → Adaugă nou → Încarcă modul → vitim-connector.zip → Activează.
2. Setări → VITIM → lipește codul de conectare primit de la VITIM → Conectează.
